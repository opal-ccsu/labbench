The AI Data Protocol, practiced. Specify, generate, verify, log.

In this course you don't download data, you order it. Here the bench plays the AI, and it fails the way chat tools really fail: wrong row counts, values out of range, a table instead of CSV, data that is too clean, output that cuts off. Write the spec, send the prompt, catch what is wrong, fix it, and walk away with a log that earns its two points. Every activity, and three of the Team Mastery assignments, have a sample prompt below.

Five steps. SPECIFY → GENERATE → VERIFY → ANALYZE → LOGUnlogged data is ungraded data. The log is 2 of the 10 points on every activity.Getting it into Excel. Copy the code block, click A1, paste. If it lands in one column: Data → Text to Columns → Delimited → Comma → Finish.

Which test do I run? Start with the dependent variable.

Excel will compute whatever you ask it to compute, including the wrong thing, without complaint. Choosing is the skill; the formula is the follow-through. "Which test?" items appear on every exam, and the Test-Selection Capstone is this skill and nothing else: identify the variables and groups, classify the design, name the test, defend it.
