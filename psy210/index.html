The AI Data Protocol, practiced. Specify, generate, verify, log.

In this course you don't download data, you order it. Here the bench plays the AI, and it fails the way chat tools really fail: wrong row counts, values out of range, a table instead of CSV, data that is too clean, output that cuts off. Write the spec, send the prompt, catch what is wrong, fix it, and walk away with a log that earns its two points.

Five steps. SPECIFY → GENERATE → VERIFY → ANALYZE → LOGUnlogged data is ungraded data. The log is 2 of the 10 points on every lab.Keep total N at 150 or below. Chat tools get unreliable past that.
The skill the practical is built on

Which test? Start with the dependent variable.

Software will run whatever you tell it to run, including the wrong thing, without complaint. The comprehensive practical hands you a dataset and research questions and nobody tells you which tests to run. This is the decision tree from class: find the DV, find the IVs, count levels, decide between or within, then name the test and say why.
