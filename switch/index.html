One-time setup: let this page press GitHub's button

This page needs a GitHub token that can run the Testing time workflow and nothing else. It is stored locked with your password, so without the password it is unreadable.

  1. Open GitHub's new fine-grained token page, signed in as the account that owns labbench.
  2. Name it Nap switch and pick an expiration, up to a year.
  3. Under Repository access choose Only select repositories, then labbench.
  4. Under Permissions, Repository, set Actions to Read and write. Leave everything else as it is.
  5. Generate the token, copy it, and paste it here.

Pages takes a minute or two to update after a press, and open benches check once a minute. Prefer GitHub's own button? Testing time on GitHub works with your GitHub login.
